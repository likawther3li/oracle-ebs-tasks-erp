# Task 2 — Design the Form on APSTAND.fmb Template

**Ticket:** 86eyxkh6e
**Tool:** Oracle Forms Builder

## Steps Performed

1. Built the DEPT and EMP data blocks directly inside the `APSTAND.fmb` template (see Task 1) instead of starting from a blank form, so the form inherits the EBS-standard toolbar, menu, and triggers.
2. Verified the module-level triggers that ship with the template (`WHEN-NEW-FORM-INSTANCE`, `ON-CLEAR-DETAILS`) were left untouched.
3. Removed the unused default objects that come pre-built in the `APSTAND.fmb` template so they wouldn't conflict with the custom blocks:
   - Data Blocks: `BLOCKNAME`, `DETAILBLOCK`, `VNDR_ADDR_DISP`
   - Canvases: `BLOCKNAME`, `VNDR_ADDR_DISP`
4. Kept the custom objects: `DEPT` block, `EMP` block, and `CANVAS142` (with `FRAME143` / `FRAME146`).
5. Compiled the module: **Program → Compile Module** → result: **"Module built successfully."**
6. Saved the file as `KAWTHER_DEPT_EMP.fmb`.
7. Uploaded `KAWTHER_DEPT_EMP.fmx` (the compiled module) to the EBS application tier server (same environment the Forms Builder session runs on via Remote Desktop, so no cross-platform recompilation was needed).

## Result
A clean, standards-compliant form built on top of the `APSTAND.fmb` template, free of leftover template placeholder objects, and successfully compiled.
