# Task 1 — Create a Master-Detail Form using DEPT and EMP Tables

**Ticket:** 86eyxkh34
**Tool:** Oracle Forms Builder

## Steps Performed

1. Opened Oracle Forms Builder and opened the `APSTAND.fmb` template file.
2. Used **File → Save As** to save the module as `KAWTHER_DEPT_EMP.fmb`.

### Master block — DEPT
3. Right-clicked **Data Blocks → New** in the Object Navigator to launch the **Data Block Wizard**.
4. Chose **Table or View**, entered `DEPT` as the table name.
5. Selected all three columns: `DEPTNO`, `DNAME`, `LOC`.
6. Set the block name to `DEPT`.
7. Chose **Yes, use the Layout Wizard**, created a **new Canvas** (Content type).
8. Arranged the fields as a **Form-style** layout, 1 record displayed, Frame Title: `DEPARTMENT`.

### Detail block — EMP
9. Created a second data block via **Data Blocks → New** based on table `EMP`.
10. Selected only 5 columns: `EMPNO`, `ENAME`, `JOB`, `SAL`, `DEPTNO` (excluded `MGR`, `HIREDATE`, `COMM`).
11. Set the block name to `EMP`.

### Master-Detail relationship
12. On the "Create Relationship" screen, used the auto-suggested relation **DEPT → FK_DEPTNO**, which set the join condition to:
   ```
   EMP.DEPTNO = DEPT.DEPTNO
   ```
13. Confirmed the relationship with **DEPT** appearing under **Master Data Blocks**.
14. Ran the Layout Wizard for the EMP block, placing it on the **same canvas** as DEPT (`CANVAS142`).
15. Chose **Tabular** layout, 5 records displayed, Distance Between Records = 0, Display Scrollbar enabled, Frame Title: `EMPLOYEES`.

## Result
A working Master-Detail form: selecting/querying a department automatically coordinates and displays its employees in the detail block below.
