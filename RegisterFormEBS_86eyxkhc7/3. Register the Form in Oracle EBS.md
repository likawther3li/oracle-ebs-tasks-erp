- Entered:

  - **Application**: `Application Object Library`
  - **User Form Name**: `KAWTHER_DEPT_EMP`
  - **Description**: `Master-Detail form for DEPT and EMP`
- Saved the record.

### 2. Create a Form Function
- Navigated to **Application Developer → Function**.
- On the **Description** tab:
  - **Function**: `KAWTHER_DEPT_EMP`
  - **User Function Name**: `KAWTHER_DEPT_EMP`
  - **Description**: `KAWTHER_DEPT_EMP MASTER-DETAIL FORM`
- On the **Form** tab:
  - Looked up and selected **Form Name**: `KAWTHER_DEPT_EMP`
  - **Application**: `Application Object Library` (auto-filled)
- Saved the record.

### 3. Add the Function to a Menu
- Navigated to **Application Developer → Menu**.
- Opened menu `KAWTHERFORM_MENU`.
- Added a new row (Seq 4):
  - **Prompt**: `KAWTHER_DEPT_EMP`
  - **Function**: `KAWTHER_DEPT_EMP`
  - **Description**: `Master-Detail form for DEPT and EMP`
  - **Grant**: checked
- Saved the record.

### 4. Test End-to-End
- Logged into Oracle Applications under responsibility **KAWTHER_FORMS_RESP**.
- Opened **KAWTHER_DEPT_EMP** from the Functions list.
- Form launched successfully, showing the **DEPARTMENT** master block and **EMPLOYEES** detail block.
- Ran a query (Deptno = 10) and confirmed the master record (ACCOUNTING, NEW YORK) returned correctly, confirming the master-detail coordination and EBS registration both work.
